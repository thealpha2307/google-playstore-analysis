# 📊 Google Play Store Analytics Dashboard

A 6-task data analytics project built during the **NullClass Data Analyst Internship**.  
Live dashboard deployed on Vercel with IST time-gated chart visibility.

**🔗 Live URL:** `https://your-project.vercel.app`

## Task Summary

| Task | Type | Key Filters | IST Window |
|------|------|-------------|------------|
| 1 | Grouped Bar | Size ≥ 10MB, Jan updates, Rating ≥ 4.0 | 3 PM – 5 PM |
| 2 | Dual-Axis | Installs ≥ 10K, Android > 4.0, Size > 15MB | 1 PM – 2 PM |
| 3 | Choropleth | Top 5 cats, Installs > 1M, Excl. A/C/G/S | 6 PM – 8 PM |
| 4 | Stacked Area | Rating ≥ 4.2, T/P categories, Size 20–80MB | 4 PM – 6 PM |
| 5 | Bubble Chart | Rating > 3.5, Subjectivity > 0.5, Installs > 50K | 5 PM – 7 PM |
| 6 | Time Series | E/C/B categories, Reviews > 500, No S in name | 6 PM – 9 PM |

## How to Run Locally

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate all chart images (run ONCE)
python generate_charts.py

# 3. Open dashboard in browser
open index.html
```

---

## Deploy to Vercel

```bash
# 1. Push to GitHub
git init
git add .
git commit -m "Google Play Store Analytics Dashboard"
git remote add origin https://github.com/YOUR_USERNAME/playstore-dashboard.git
git push -u origin main

# 2. Go to vercel.com → New Project → Import repo → Deploy
# No build settings needed — Vercel serves index.html automatically
```
